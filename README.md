# OfficeStudio

Десктопное приложение для Windows: документы Word (**.docx**), таблицы Excel (**.xlsx / .csv**), презентации PowerPoint (**.pptx**) и чертежи AutoCAD (**.dwg / .dxf**) — открыть, создать, отредактировать и сохранить в одном окне с вкладками.

## Установка

- **OfficeStudio-Setup-1.4.0.exe** — обычный установщик (можно выбрать папку, создаёт ярлык, связывает .docx/.xlsx/.pptx/.dwg/.dxf).
- **OfficeStudio-Portable-1.4.0.exe** — без установки, просто запустить.

Установщик не подписан цифровой подписью, поэтому Windows SmartScreen может показать «Windows защитила ваш компьютер» → **Подробнее** → **Выполнить в любом случае**.

## Что умеет

**Документы (.docx)**
- Стили (Обычный, Заголовок 1–3, Цитата), шрифт, размер, жирный/курсив/подчёркнутый/зачёркнутый, над/подстрочный, цвет текста и выделения.
- Выравнивание, маркированные и нумерованные списки, отступы.
- Таблицы (вставка сеткой, правый клик — строки/столбцы/заливка), рисунки (вставка, вставка из буфера, перетаскивание, изменение размера мышью), ссылки, линия, разрыв страницы.
- **Линейка** над страницей, как в Word: треугольники и квадратик задают красную строку, выступ, отступ слева и справа (тянуть мышью, шаг 0,25 см, с Alt — без шага). Двойной щелчок по линейке или кнопка **«Абзац»** — точные значения в сантиметрах, интервалы перед/после и междустрочный. Кнопки «Увеличить/Уменьшить отступ» сдвигают абзац на 1,25 см. Всё это сохраняется в .docx и читается обратно.
- Найти и заменить (Ctrl+F), счётчик слов, масштаб, проверка орфографии (рус/англ).
- Экспорт в **PDF**, сохранение в .docx или .html. Открывает также .txt, .md, .html.

**Таблицы (.xlsx, .csv)**
- Листы как в Excel: ввод в ячейку или в строку формул, F2 — правка, Alt+Enter — новая строка внутри ячейки, Ctrl+стрелки — к краю данных, Shift — выделение, Ctrl+A, PageUp/PageDown.
- **Формулы с пересчётом** (около 400 функций: СУММ, СРЗНАЧ, ЕСЛИ, ВПР, СУММЕСЛИ, СЧЁТЕСЛИ, ОКРУГЛ, СЕГОДНЯ, текстовые, даты, финансовые…). Писать можно по-русски через «;» — `=СУММ(A1;A2)` — или по-английски — `=SUM(A1,A2)`. Ссылки на другие листы, абсолютные ссылки (F4 переключает `$`), клик по ячейкам во время набора формулы вставляет их адрес. Σ (Alt+=) — автосумма.
- Понимает ввод `3,5`, `15%`, `1500 ₽`, `26.10.2026`, `9:30`, ИСТИНА/ЛОЖЬ; апостроф в начале — «как текст».
- Форматы чисел: общий, числовой, с разделителями, денежный (₽, $, €), процентный, дата, время, текстовый, ± разрядность. Сохраняются форматы из файла Excel.
- Шрифт, размер, жирный/курсив/подчёркнутый/зачёркнутый, цвет текста, заливка, выравнивание по горизонтали и вертикали, перенос текста, **границы**, объединение ячеек.
- Маркер заполнения (квадратик в углу выделения): тянете — числа продолжают ряд (1, 2 → 3, 4, 5…), формулы копируются со сдвигом ссылок.
- Вставка/удаление строк и столбцов (формулы сдвигаются сами), сортировка А→Я / Я→А, ширина столбцов и высота строк мышью (двойной клик по границе — по содержимому), **закрепление** строк/столбцов, поиск (Ctrl+F, F3 — дальше), масштаб.
- Копирование/вставка с Excel, Word и браузером в обе стороны (Ctrl+C / Ctrl+X / Ctrl+V).
- Листы: добавить, переименовать (двойной клик по ярлыку), удалить. Внизу — сумма, среднее и количество для выделения.
- Отмена/повтор любых действий (Ctrl+Z / Ctrl+Y).
- Сохранение в **.xlsx** (открывается в Excel, LibreOffice, Google Таблицах — формулы и оформление сохраняются) или **.csv** (разделитель «;», UTF-8 — Excel открывает русские буквы правильно). CSV в кодировке Windows-1251 тоже открывается.

**Презентации (.pptx)**
- Миниатюры слайдов: добавить (4 макета), дублировать, удалить, перетащить для смены порядка.
- Надписи, 12 видов фигур, рисунки, таблицы. Перемещение, изменение размера, поворот (Shift — шаг 15°), умные направляющие при перетаскивании.
- Форматирование текста (шрифт, размер, цвета, выравнивание, маркеры, нумерация) — для всего блока или выделенного фрагмента при редактировании (двойной щелчок).
- Заливка, контур и его толщина, порядок слоёв, фон слайда (цвет/картинка), размер слайдов (16:9, 4:3, 16:10, A4).
- Заметки докладчика, полноэкранный **показ слайдов (F5)**, отмена/повтор.

**Чертежи (.dwg, .dxf)**
- Открытие DWG версий R14–2018 и DXF. **Большие чертежи** (100 МБ DWG и больше) открываются отдельной программой-конвертером, которая берёт столько памяти, сколько нужно, — как правило, за 20–60 секунд. Слои (видимость, цвет, текущий слой, «показать только этот слой»), блоки и массивы блоков, значения атрибутов, размеры, тексты, сплайны, эллипсы, **штриховки** (сплошные и с узором), полигональные сетки.
- **Движок на Rust** (WebAssembly) и отрисовка через видеокарту (WebGL2): чертёж на ~400 тыс. элементов открывается примерно за секунду, выбор объекта кликом — сотые доли миллисекунды, панорама и зум без пересчёта геометрии. Без видеокарты (удалённый рабочий стол, виртуальная машина) автоматически включается программная отрисовка.
- Инструменты: отрезок, полилиния, прямоугольник, окружность, дуга по 3 точкам, текст, размер; перенос, копирование, поворот, зеркало, удаление, редактирование ручками (синие квадраты).
- Командная строка как в AutoCAD: `L`, `PL`, `REC`, `C`, `A`, `T`, `DIM`, `M`, `CO`, `RO`, `MI`, `E`, `Z`, `DI` (измерить). Координаты: `100,50`, `@20,0`, `@50<45`, или просто число — длина по направлению курсора. Enter/пробел — повтор последней команды.
- Объектная привязка (конец, середина, центр — F3), сетка (F7), шаг (F9), орто (F8).
- Панель свойств: слой, цвет, точные координаты/радиус/текст выделенного объекта.
- **Прозрачность** слоёв и объектов, как в AutoCAD; заливки накладываются друг на друга в том порядке, в каком записаны в чертеже.
- «Показать всё» не учитывает пустые блоки и одиночные объекты, улетевшие за сотни километров от чертежа, — чертёж не превращается в точку.
- **Фон чертежа** — кнопка «Фон» на панели: тёмный, чёрный, синий «калька», серый, светло-серый, бумага, белый или любой свой цвет. Выбор запоминается для всех чертежей. На светлом фоне белые линии автоматически становятся чёрными, а бледные (жёлтые, голубые) — темнее, чтобы их было видно; это можно выключить, а можно наоборот включить режим «все линии одним цветом». На цвета в самом файле фон не влияет.
- Сохранение в **DXF** (AutoCAD R12 — открывается в AutoCAD, BricsCAD, nanoCAD, LibreCAD, КОМПАС и т.д.), экспорт в PNG (на белом или на текущем фоне).

**Красный карандаш (пометки) — в документах, презентациях и чертежах**
- Кнопка **«Карандаш»** на панели: рисуйте мышью поверх документа, слайда или чертежа. **Esc** — выход из режима.
- **Ластик** стирает пометку целиком, если по ней провести. **Корзина с волной** удаляет все пометки разом. **Ctrl+Z** отменяет.
- Пометки сохраняются в сам файл и видны в других программах:
  - **DWG/DXF** — красные полилинии на отдельном слое «Пометки» (в AutoCAD его можно скрыть или удалить). Ластик трогает только этот слой, сам чертёж не стирается.
  - **PPTX** — векторные кривые на слайде (видны в PowerPoint, их можно двигать и масштабировать).
  - **DOCX** — плавающие рисунки, привязанные к абзацу (видны в Word и едут вместе с текстом). При повторном открытии в OfficeStudio снова становятся редактируемыми штрихами. В экспорт PDF тоже попадают.

## Честно об ограничениях

- **DWG только читается.** Формат закрытый; записать его без платной библиотеки ODA нельзя. Поэтому DWG сохраняется в DXF. Если нужен именно DWG — бесплатный [ODA File Converter](https://www.opendesign.com/guestfiles/oda_file_converter) переводит DXF→DWG.
- Старые форматы **.doc / .xls / .ppt** (Office 97–2003) не поддерживаются — пересохраните их в .docx/.xlsx/.pptx.
- В таблицах не отображаются диаграммы, картинки, условное форматирование, сводные таблицы и макросы — при сохранении они не переносятся (файлы .xlsm открываются, но сохраняются как .xlsx). Отдельные редкие функции Excel могут дать #ИМЯ?.
- Документ показывается одной длинной страницей (разрывы страниц видны как пунктир). Колонтитулы, сноски, рецензирование, SmartArt и диаграммы PowerPoint не редактируются (диаграммы показываются как заглушка), анимации слайдов не сохраняются.
- DXF сохраняется в формате R12, в нём нет прозрачности: после сохранения прозрачность слоёв не сохранится (в исходном DWG она остаётся).
- В чертежах не отображаются тела ACIS (3DSOLID, REGION), мультивыноски (MULTILEADER), маскировки (WIPEOUT) и бесконечные прямые (XLINE/RAY). Штриховки при сохранении в DXF R12 записываются как блок с заливкой/линиями узора (в R12 нет объекта HATCH).

## Сборка из исходников

Нужен Node.js 20+.

```
npm install
npm start            # запуск в режиме разработки
npm run dist:win     # сборка установщика и portable в папку dist/
```

Чертёжный движок — Rust-проект в папке `cadcore/` (разбор DXF, геометрия, R-дерево, правки с отменой, запись DXF). Готовый WebAssembly уже лежит в `src/renderer/cadcore/`, пересобирать его нужно только после изменений в Rust:

```
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version 0.2.104
cadcore/build-wasm.sh
cd cadcore && CAD_SAMPLES=<папка с примерами> cargo test --release   # тесты движка
```

Структура: `src/main.js` — главный процесс (диалоги, файлы), `src/converters/` — конвертеры форматов, `src/renderer/` — интерфейс и четыре редактора (`sheet-editor.js` — таблицы, формулы считает HyperFormula) (`cad-gl.js` — отрисовка чертежей через WebGL2), `cadcore/` — движок чертежей на Rust. `test/smoke-main.js` — сквозной автотест документов, презентаций и чертежей, `test/sheet-main.js` — автотест таблиц (ввод с клавиатуры, формулы, маркер заполнения, сохранение и повторное открытие).

Конвертер DWG → DXF (`bin/win/dwg2dxf.exe`) — программа `dwg2dxf` из LibreDWG, собранная для Windows скриптом `tools/build-dwg2dxf.sh` (версия — в `bin/LIBREDWG_COMMIT`).
